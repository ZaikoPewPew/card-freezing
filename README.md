# Card freezing

Заморозка карты: на экране только карта и кнопка. Карта двигается как конверт из convert-card: влетает с разворотом, покачивается, наклоняется за курсором, сжимается при нажатии. Иней рисуется кодом в разрешении экрана ([frost.ts](src/frost.ts)), звуки синтезируются ([sound.ts](src/sound.ts)). Кнопка внизу запускает волну [distortion-waves](https://libraries.dev/waves) (тип `vertical`, палитра `ocean`), которая поднимается от кнопки и переносит экран активной карты в замороженный. Повторное нажатие сворачивает волну обратно в кнопку.

Фон, бумажная текстура, фольга и белая кнопка взяты из [convert-card](https://github.com/ZaikoPewPew/convert-card).

```bash
npm install
npm run dev
```
