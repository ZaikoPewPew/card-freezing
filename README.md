# Card freezing

Заморозка карты: кнопка внизу запускает волну [distortion-waves](https://libraries.dev/waves) (тип `vertical`, палитра `ocean`), которая поднимается от кнопки и переносит экран активной карты в замороженный. Повторное нажатие сворачивает волну обратно в кнопку.

Фон, бумажная текстура, фольга и белая кнопка взяты из [convert-card](https://github.com/ZaikoPewPew/convert-card).

```bash
npm install
npm run dev
```
