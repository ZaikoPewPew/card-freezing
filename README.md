# Card freezing

Заморозка карты: на экране только карта и кнопка. Карта двигается как конверт из convert-card: влетает с разворотом, покачивается, наклоняется за курсором, сжимается при нажатии. Кнопка внизу запускает волну [distortion-waves](https://libraries.dev/waves) (тип `vertical`, палитра `ocean`) только по лицевой стороне карты, в её скруглённых углах. Волна только накатывает цвет поверх (`capture={false}`), сама PNG карты никогда не изгибается. Под волной проявляются холодный оттенок и иней: он постепенно нарастает от краёв, как стекло замерзает на таймлапсе ([frost.ts](src/frost.ts)), фон остывает с тёплого на холодный. Звуки льда синтезируются ([sound.ts](src/sound.ts)). При разморозке тёплая волна (`sunset`) стирает лёд снизу вверх.

Фон, бумажная текстура, фольга и белая кнопка взяты из [convert-card](https://github.com/ZaikoPewPew/convert-card).

```bash
npm install
npm run dev
```
