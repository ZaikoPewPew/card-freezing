# Card freezing

Заморозка карты: на экране только карта и кнопка. Карта двигается как конверт из convert-card: влетает с разворотом, покачивается, наклоняется за курсором, сжимается при нажатии. Кнопка внизу запускает волну [distortion-waves](https://libraries.dev/waves) (тип `vertical`, палитра `ocean`) только по лицевой стороне карты, в её скруглённых углах. Линза волны изгибает карту и переводит её из тёплого вида в замороженный; иней под ней нарастает от краёв ([frost.ts](src/frost.ts)), фон остывает. Разморозка — обратный ход той же волны: она стягивается сверху вниз обратно к кнопке. Звуки льда синтезируются из шума ([sound.ts](src/sound.ts)).

Фон, бумажная текстура, фольга и белая кнопка взяты из [convert-card](https://github.com/ZaikoPewPew/convert-card).

```bash
npm install
npm run dev
```
